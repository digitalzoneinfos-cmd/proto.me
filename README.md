# أريام — لوحة التقارير (React + Supabase)

تطبيق ويب (يعمل على الهاتف والحاسوب، ويمكن تثبيته كتطبيق PWA) للأدمن والمسيّرين:

| الصفحة | الأدمن | المسيّر |
|---|---|---|
| نظرة عامة (صافي، بطاقة، كاش، مصاريف، رسم بياني، متابعة اليوم) | ✔ | ✔ |
| التقرير اليومي (أي تاريخ) + صورة Day Close + وصولات اليوم | ✔ تعديل | ✔ اطلاع |
| التقرير الشهري بنفس تنسيق تقرير المكتبة — طباعة / PDF / Excel / تعديل النصوص | ✔ | ✔ (بدون تعديل) |
| إدخال المداخيل (بطاقة، كاش، أخرى، صورة التقرير) مع حساب تلقائي | ✔ | — |
| المصاريف + معاينة صورة/ملف الوصل لكل مصروف | ✔ إضافة/تعديل/حذف | ✔ اطلاع |
| مستلزمات المتجر / الاقتراحات / انشغالات الطاقم (الحالات: جديد، قيد المعالجة، تم) | ✔ | ✔ اطلاع |
| الموردون + واتساب واتصال مباشر | ✔ | ✔ |
| كود الدعوة السري، الأعضاء، معلومات المتجر | ✔ | — |

## 1) إعداد Supabase (5 دقائق)

1. أنشئ مشروعاً في <https://supabase.com>.
2. افتح **SQL Editor → New query**، الصق محتوى `supabase/schema.sql` كاملاً، ثم **Run**.
   ينشئ الجداول، صلاحيات RLS (المسيّر يقرأ فقط، الأدمن يكتب)، حاوية التخزين الخاصة `files`، ودوال كود الدعوة.
3. **Authentication → Providers → Email**: فعّل Email.
   (اختياري) أوقف *Confirm email* إذا أردت الدخول مباشرة بعد إنشاء الحساب.
4. **Authentication → URL Configuration**: ضع رابط موقعك في *Site URL*.
5. **Project Settings → API**: انسخ `Project URL` و `anon public key`.

## 2) التشغيل محلياً

```bash
npm install
cp .env.example .env.local     # ثم ضع المفتاحين
npm run dev
```

> بدون ملف `.env.local` يعمل التطبيق في **الوضع التجريبي** ببيانات نوفمبر 2026 (محفوظة في المتصفح فقط).

## 3) النشر (Vercel أو Netlify)

- Build command: `npm run build` — Output: `dist`
- أضف متغيري البيئة `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY`.

## 4) أول استعمال

1. الأدمن يدخل من الرابط `/#/admin` → حساب جديد → يُنشئ المتجر → يحصل على **كود الدعوة**.
2. الإعدادات → إرسال الكود عبر واتساب للمسيّرين.
3. المسيّر: حساب جديد من الصفحة الرئيسية → يُطلب منه الكود → يدخل إلى بيانات المتجر.
4. "توليد كود جديد" يوقف الكود القديم فوراً، و"إزالة" تسحب صلاحية أي مسيّر.

## الطباعة والتحميل
- **طباعة / حفظ PDF**: اختر "Save as PDF" في نافذة الطباعة، الحجم A4، الهوامش: بدون.
- **Excel**: ثلاث أوراق (المداخيل اليومية، تفصيل المصاريف، حسب الفئة) قابلة للتعديل.
- **تعديل النصوص**: (موجّه إلى، العنوان، الملاحظة، الخلاصة، من إعداد…) تُحفظ لكل تقرير، والقيم العامة (الملاحظة، المُعِدّ) تصبح افتراضية للتقارير القادمة.
